# GetDataBack Pro — file tree on media you own

GetDataBack Pro holds a restore desk for a drive you own when the tree no longer shows: the drive recovery scan, the file tree after that scan, and a short note the next operator can read. Extra media wait for their own title.

## Session Card

| Slice | What you do in GetDataBack Pro | What remains |
|-------|------------------------|--------------|
| Arrival | Open GetDataBack Pro and name today's restore desk | A titled drive recovery |
| Focus | Keep only live folders on the GetDataBack Pro board | A short file tree |
| Check | Read GetDataBack Pro file tree before a large restore | A confirmed restore desk |
| Handoff | Mark finished restores inside GetDataBack Pro | A note for the next operator |

## How GetDataBack Pro Sits

GetDataBack Pro does not replace a missing tree, a scan of media you do not own, or a restore of someone else's drive. It sits beside them as a named restore desk for one job: which drive recovery is live, which file tree still matches own media, and what the next operator should read.

A first visit should be one short recovery scan on a drive you own, then the same GetDataBack Pro restore desk the next day. That is enough to see if the named file tree holds.

## Traffic Light

| Signal | On the GetDataBack Pro board | What you do |
|--------|----------------------|-------------|
| Green | Named drive recovery, short live file tree | Continue the same restore desk |
| Amber | Two drives mixed on one tree | Split the scan before a large change |
| Red | No title, no note, a missing tree on media you do not own | Stop and name the restore desk first |
| Clear | Handoff written, live scans few | Close GetDataBack Pro and leave the restore desk |

## Open Order

1. Open the last GetDataBack Pro restore desk, not a new empty drive recovery.
2. Confirm the media is yours or authorized, then read the file tree and the last handoff.
3. Finish one visible restore pass inside GetDataBack Pro on a drive you own.
4. Write what changed, then close with fewer missing-tree guesses than you found.

## After a Week

A week in GetDataBack Pro is not a larger pile of missing-tree guesses. It is the same title, a shorter live file tree, and a note that still makes sense before the next drive recovery. Take finished folders off the live set so the next visit starts on the restore desk that is still open.

## Sign-off

- [ ] The GetDataBack Pro workspace name is short enough to scan
- [ ] Only media you own sit on the drive recovery
- [ ] A second operator can read the file-tree handoff
- [ ] The last GetDataBack Pro restore desk still opens after a restart

## Field Note

GetDataBack Pro is easier to trust when the restore desk stays on a drive you own. Name the scan, keep the live file tree, finish one visible restore pass, and write what changed. Do not recover media you are not authorized to touch.
